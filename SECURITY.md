Security Policy

About PHANTOM

PHANTOM is an AI-enhanced security assessment and penetration testing framework designed for authorized security research, defensive security testing, education, and controlled environments.

The project is currently paused and provided as a research/engineering project. It is not represented as a production-ready commercial security platform.

Responsible Use

PHANTOM contains capabilities that can interact with systems in ways that may have security impact, including vulnerability detection, authentication testing, exploit validation, and attack-chain analysis.

Only use PHANTOM against:

- Systems you own
- Systems where you have explicit authorization to test
- Dedicated security testing environments
- Bug bounty targets within their published scope and rules
- Other environments where security testing is explicitly permitted

Do not use PHANTOM to gain unauthorized access, access data without permission, disrupt services, or bypass the rules of a security program.

Users are responsible for complying with applicable laws, regulations, contracts, and program policies.

Reporting a Security Issue

If you discover a security vulnerability in PHANTOM itself, please report it responsibly.

Please include:

- A description of the vulnerability
- The affected component or file
- Steps to reproduce
- Potential security impact
- A proof of concept, when appropriate
- Any suggested mitigation

Please avoid publicly disclosing the vulnerability before a reasonable opportunity has been provided to investigate and address it.

Scope

Security issues in the following areas are particularly relevant:

- Authentication and authorization
- Scope enforcement
- Safety-mode enforcement
- Exploit policy enforcement
- SSRF or scope-escape protections
- Credential or secret handling
- Sensitive data exposure
- Unsafe command execution
- Dependency vulnerabilities
- Container or deployment security
- Findings or reports leaking sensitive information

Out of Scope

The following are generally not considered security vulnerabilities in PHANTOM:

- Vulnerabilities in third-party tools integrated by PHANTOM
- Vulnerabilities in target applications scanned using PHANTOM
- Findings that require unauthorized use of the framework
- Issues caused exclusively by intentionally insecure test targets
- Missing features or incomplete modules

Disclosure

Please use responsible disclosure when reporting security issues.

Security research involving PHANTOM should be conducted in controlled environments and in accordance with applicable laws and authorization requirements.
